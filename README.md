# DeadPunk OS GitHub Page

This branch contains the static GitHub Page for the XxYouDeaDPunKxX profile.

The profile README lives on `main`.

## Structure

```text
index.html   page shell and SEO fallback
style.css    visual system
projects.js  project data
app.js       module rendering and inspector interaction
```

## Add a project

Edit `projects.js` and add one object to `PROJECTS`.

No layout changes should be required for a normal new project.
